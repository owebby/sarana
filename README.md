# Sarana — Rajasarana Connect

Sistem aplikasi terhubung untuk CV Raja Sarana Makmurindo (rajasarana.com), jasa trucking di Cikarang Utara.

Tiga aplikasi, satu data:
- **Pelanggan**: pesan truk, estimasi harga, lacak posisi truk, bukti terima, tagihan.
- **Sopir**: terima tugas, foto surat jalan, status perjalanan, bukti terima (tanda tangan), lapor biaya jalan.
- **Kantor & owner**: setujui order + harga final, tugaskan truk & sopir, pantau armada, invoice otomatis, margin & piutang.

## Demo (prototipe klik)
`demo/index.html` — satu file HTML mandiri, buka langsung di browser. Data contoh, tersimpan di localStorage browser (tombol "Ulang demo" untuk reset).

Status: prototipe untuk pitching, belum dibahas dengan klien. Versi produksi (Android Kotlin + PHP/MySQL) menyusul setelah masukan klien.
